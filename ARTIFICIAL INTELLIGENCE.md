# What is AI ?
##  Artificial Intelligence (AI) is when machines are designed to learn, think, and make decisions like humans. 
##  However, unlike humans, machines do not have emotions or consciousness. 
##  They learn by using data — lots of data — to recognize patterns, solve problems, and improve their performance over time.

### AI is the ability of machines to simulate human intelligence by learning, thinking, and making decisions.

# One AI - Many Favors 
1. Machine Learning
2. Deep Learning
3. Generative AI
4. Natural Language Processing
5. Computer Vision

## Machine Learning [ML]
->   Machine Learning is a type of Artificial Intelligence where an ML model learns from data and experience, without being explicitly programmed. 
### The goal of machine learning is to:
1. Enable the model to learn patterns from data
2. Use this learning to make predictions or decisions automatically over time

## Deep Learning [DP]
-> Deep Learning is a type of machine learning that uses multilayer neural networks to learn from large amounts of data. 
### The goal of deep learning is to:
1. Automatically learn complex patterns from large and complex data
2. Perform tasks like image recognition, speech recognition, and language understanding with high accuracy

## Generative AI [Gen AI]
-> Generative AI is a type of AI that can create new content such as text, images, music, or code based on what it has learned. 
### The goal of generative AI is to:
Learn patterns from existing data

## Natural Language Processing [NLP]
-> Natural Language Processing is a field of AI that enables machines to understand, interpret, and respond to human language. 
### The goal of NLP is to:
1. Help machines understand text and speech
2. Enable communication between humans and machines using natural language

## Computer Vision [CV]
-> Computer Vision is a field of AI that enables machines to see, analyze, and understand images and videos. 
### The goal of computer vision is to:
1. Teach machines to recognize objects, faces, and scenes
2. Use visual information to make decisions or take actions
3. Generate new and meaningful content similar to human‑created content
